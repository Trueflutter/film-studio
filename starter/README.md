# My AI film studio

1. Install the plugin once (in Claude Code):
   ```
   /plugin marketplace add <your course's studio repo>
   /plugin install film-studio@saqr-film
   ```
2. Copy this folder somewhere you keep projects, rename it, and open Claude Code in it.
3. `cp .env.example .env` and add your keys.
4. When Claude Code asks, approve the Higgsfield and ElevenLabs connectors (`.mcp.json`) and sign in with your accounts.
5. In Claude Code type `!film doctor`, then `!film new "My First Film"` (or ask Claude to do it).

Everything else: ask Claude. It has the `studio` skill and the handbook.
